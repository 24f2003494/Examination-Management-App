# Examination Management Portal

A web-based Examination Management Portal developed as part of the Modern Application Development I (MAD-I) project.

The application uses Flask, Jinja2, HTML, CSS, Bootstrap, and SQLite.

It supports three user roles:
- Admin
- Examiner
- Student

The portal manages examinations, examination slots, student bookings, and evaluations.# Examination-Management-App
